# プロジェクトのメール設定

プロジェクトの設定の「メール」のタブで、プロジェクトのメールの受け取り方を設定します。プロジェクトのアドレス、「メール受信」、メールから作るチケットの値です。このタブは、「メール設定の管理」の権限のあるメンバーに表示されます。「未登録の送信者」の「ユーザーを作成」を選べるのも、転送の設定を変えられるのも、システム管理者だけです。転送の設定は、「転送元」(DMARC に失敗しても転送メールを取得するアドレスまたはドメイン)、「転送メール」(メンバーが転送したメールを元のメールとして取得し、メンバーをウォッチャーにして注記を残す)、「転送メールの作成者」(作成者にしてよい元の差出人) です。メンバーには無効のフィールドで表示します。

詳しくは [Redmine AWS SES のプロジェクトのメール設定](https://redmine-kit.github.io/redmine_aws_ses/ja/admin.html#project-email-settings) を参照してください。
