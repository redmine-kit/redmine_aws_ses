# メールの送信

「管理」›「AWS」›「メール送信」には、Amazon SES での Redmine のメールの状態を表示します。「SES アカウント」(「アカウントステータス」、「送信」、「本稼働アクセス」、「日次送信クォータ」、「直近 24 時間の送信数」、「最大送信レート」)、「ドメイン」(「検証済み」と DKIM)、SES が送らないアドレスの「サプレッションリスト」です。

表示するのは、最後に読んだときの状態です (右上の「更新」)。スケジュールで読み、「最新の情報に更新」で読み直します。

メールボックスが使えるようになったら、システム管理者はこのページでそのアドレスをサプレッションリストから外します。

詳しくは [Redmine AWS SES の管理画面](https://redmine-kit.github.io/redmine_aws_ses/ja/admin.html) を参照してください。
