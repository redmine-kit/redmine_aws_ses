# メールの送信

Redmine Kit AWS SES は、Redmine のメールを Amazon SES で送信します。「管理」›「AWS」›「メール送信」には、Redmine のメールに関する SES の状態を表示します。開けるのはシステム管理者だけです。

表示するのは最後に読み込んだときの状態で、右上にその日時 (「更新: …」) を表示します。スケジュールで実行する rake タスク (`redmine_kit:aws:ses:refresh`) が読み込み、「最新の情報に更新」ですぐに読み込み直します。タブを開いても AWS の API は呼びません。

## SES アカウント

SES アカウントの「アカウントステータス」、「送信」、「本稼働アクセス」、「日次送信クォータ」、「直近 24 時間の送信数」、「最大送信レート」です。「テストメールを送信」は、自分にテストメールを送る Redmine のリンクです。Redmine Kit AWS SQS をインストールしていれば、「失敗したジョブ」で、その「ジョブ」タブを失敗したメールのジョブで開きます。

## ドメイン

Redmine の「送信元メールアドレス」(「管理」›「設定」›「メール通知」) のドメインと、SES での「検証済み」と DKIM の状態です。送信元メールアドレスにドメインがないときは、SES で検証したドメインのアドレスにするよう表示します。

## サプレッションリスト

「バウンス」や「苦情」のあと SES が送信しないアドレスを、そのアドレスの Redmine のユーザーとともに表示します。メールボックスが使えるようになったら、「削除」でそのアドレスをリストから外します。
