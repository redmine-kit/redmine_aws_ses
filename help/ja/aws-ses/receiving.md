# メールの受信

「管理」›「AWS」›「メール受信」には、Redmine がメールを受け取る「メールアドレス」(デフォルトアドレスとプロジェクトごとのアドレス)、SES の判定と Redmine の扱いの付いた「受信履歴」、「受信設定」(DMARC を通らないメールや、SES が迷惑メールと判定したメールも取得するか、デフォルトのプロジェクト、プロジェクトごとのアドレス) を表示します。

SES がウイルスを見つけたメールは、いつも取得しません。

詳しくは [Redmine AWS SES の管理画面](https://redmine-kit.github.io/redmine_aws_ses/ja/admin.html) と [メールの受信](https://redmine-kit.github.io/redmine_aws_ses/ja/receiving.html) を参照してください。
