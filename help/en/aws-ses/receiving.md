# Receiving email

Administration › AWS › **Email receiving** shows the **Addresses** Redmine receives email at (the global address and each project's), the **Received email** with SES's verdicts and what Redmine did with each message, and the receiving settings: which messages to take in (for example messages that fail DMARC or that SES marks as spam), the default project, and the projects' own addresses.

Messages SES finds a virus in are never taken in.

More: [Redmine AWS SES: administration pages](https://redmine-kit.github.io/redmine_aws_ses/admin.html) and [receiving email](https://redmine-kit.github.io/redmine_aws_ses/receiving.html).
