# Project email settings

The project settings tab **Email** sets how the project receives email: whether it receives email, its address, and the values of the issues created from email. It is shown to members with the permission **Manage email settings**. Only administrators can choose **Create a user** for **Unknown senders**.

More: [Redmine AWS SES: project email settings](https://redmine-kit.github.io/redmine_aws_ses/admin.html#project-email-settings).
